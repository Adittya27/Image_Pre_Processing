# 🖼️ Image Preprocessing with Python

A hands-on implementation of fundamental **Image Preprocessing techniques using Python, Pillow (PIL), and NumPy**.

This file demonstrates how images can be loaded, inspected, transformed, and enhanced before being used in **Machine Learning and Computer Vision** applications.

Image preprocessing is an important step in computer vision and machine learning pipelines. Raw images often need to be transformed into a suitable format before they can be provided to a model.

In this notebook, I explored different image preprocessing operations using Python and the **Pillow (PIL)** library.

## 🛠️ Technologies Used

* Python
* Pillow (PIL)
* NumPy
* Jupyter Notebook / Google Colab

## 📚 Topics Covered

### 1. Importing Libraries

Imported the required Python libraries for image processing and numerical operations.

### 2. Loading an Image

Loaded an image using Pillow and inspected the image object.

### 3. Understanding Image Properties

Explored important image properties such as:

* Image size
* Image mode
* Image format
* Image dimensions

### 4. Image and NumPy Array

Explored how images can be represented as NumPy arrays and worked with their pixel values.

### 5. RGB Channels

Examined the three color channels of an RGB image:

* Red
* Green
* Blue

### 6. Image Resizing

Changed the dimensions of an image to understand how resizing works and why it is useful for creating images with consistent dimensions.

### 7. Image Rotation

Rotated images by different angles to understand geometric transformations.

### 8. Mirroring and Flipping

Applied horizontal and vertical transformations to images.

### 9. Image Cropping

Selected specific regions of an image by cropping unwanted portions.

### 10. Grayscale Conversion

Converted a color image into grayscale to reduce the image to a single intensity channel.

### 11. Image Blurring

Applied blurring techniques to reduce image details and smooth the image.

### 12. Image Sharpening

Enhanced image details using sharpening techniques.

### 13. Brightness Enhancement

Modified image brightness to understand basic image enhancement.

### 14. RGB Channel Extraction

Separated the individual Red, Green, and Blue channels and visualized them independently.
